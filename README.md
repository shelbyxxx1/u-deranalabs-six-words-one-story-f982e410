make.fun entry for **Six Words, One Story** — a program that writes one
complete story in exactly six words to `/output/entry.txt`.

## The story

> Mother baked his favorite cake alone.

Six words, 37 characters. A mother keeps baking the cake her son loved,
alone now — a whole life of loss held in a single ritual.

## Run

```sh
node main.ts
```

Writes `entry.txt` into `/output` by default, or into
`$MAKEFUN_OUTPUT_DIR` when set. The program clears stale files inside the
output directory one by one and never removes the directory itself.
